# حديقة الإنجليزية · English Garden

تطبيق ويب قابل للتثبيت للموبايل، مستقل تمامًا عن نظام المنح. يعمل الآن كتجربة محلية على `http://localhost:8091`.

## التشغيل

يتطلب Node.js حديثًا؛ لا توجد حزم خارجية مطلوبة:

```powershell
node server.mjs
```

افتح العنوان أعلاه. أمر الاختبارات: `node --test tests.mjs`.

## ما يعمل في النسخة الأولى

- سبع مراحل من KG1 إلى الصف السادس، أربع وحدات لكل مرحلة: 28 درسًا و168 بطاقة كلمة بترجمة عربية.
- كلمات، محادثة من أربع جمل، شرح جملة وقاعدة، وتدريب من ثمانية أسئلة لكل درس.
- استماع باستخدام أصوات الجهاز، وتلميحات عربية. الصوت يعتمد على دعم النظام والأصوات المثبتة؛ لا توجد تسجيلات بشرية بعد.
- ألعاب مطابقة وكلمات، حروف كبيرة وصغيرة، نجوم وشارات وتحديات فردية.
- دخول كضيف وحفظ محلي، وحساب ولي أمر بكلمة مرور مشتقة باستخدام PBKDF2 وملح مستقل لكل حساب.
- ملف طفل واحد لكل حساب، تقرير تقدم حسب المرحلة، كلمات ضعيفة للمراجعة، وأفضل نتيجة محفوظة.
- استكمال تمرين بعد إغلاق الصفحة. تحويل الضيف إلى حساب جديد ينقل تقدمه؛ تسجيل الدخول لحساب موجود يستعيد تقدم ذلك الحساب دون خلطه بضيف مختلف.
- Service Worker لتخزين الواجهة والمحتوى بعد أول تحميل. التعلم المحلي يعمل دون اتصال، والحسابات والمزامنة تحتاج الخادم. الخط الخارجي اختياري وله بدائل محلية.

## حدود واضحة

هذه وحدات تأسيسية أصلية، وليست منهجًا مدرسيًا كاملًا أو نسخة مطابقة لسلسلة Cambridge/Oxford بعينها. المحتوى يحتاج مراجعة معلم وتجربة أطفال قبل إطلاقه العام. حديقة الحروف تعلم أسماء الحروف؛ لا تمثل منهج phonics كاملًا.

التطبيق لم يُنشر في المتاجر. تثبيته يعتمد على دعم المتصفح للـPWA. التشغيل على localhost للمراجعة على هذا الكمبيوتر؛ لا يمكن للهاتف الآخر الوصول إلى localhost هذا الجهاز. الاستخدام على هواتف أخرى يحتاج استضافة HTTPS عامة أو بيئة اختبار مناسبة. لا تغير الخادم إلى استماع عام دون إعداد الاستضافة والحماية.

لا توجد استعادة كلمة مرور أو بريد تأكيد أو مسابقات جماعية أو إدارة مدرسية في هذه النسخة. لا توجد تسجيلات صوت الطفل أو محادثة AI مفتوحة. نتائج التدريب مؤشرات داخل التطبيق وليست شهادات مستوى.

## البيانات

`data/accounts.json` يحتوي بريد ولي الأمر، مشتق كلمة المرور، اسمًا مستعارًا وتقدم التعلم. لا يُخدّم عبر HTTP. لا تضع هذا المجلد في مسار static ولا تودع بياناته في Git. البيانات المحلية للضيف في LocalStorage وقد تُحذف مع بيانات المتصفح. الجلسات في ذاكرة الخادم، لذلك إعادة تشغيله تتطلب تسجيل دخول جديد دون فقدان الحسابات.

## تطوير المرحلة التالية

تحديد سلسلة الكتب وإصدارها؛ مراجعة تربوية وphonics؛ تسجيل صوت بشري؛ وحدات أكثر؛ ملفات متعددة للأطفال؛ إدارة محتوى؛ استعادة كلمة المرور؛ اختبارات معلمين وأطفال؛ ثم الاستضافة ونشر تطبيق المتاجر عند الحاجة.
